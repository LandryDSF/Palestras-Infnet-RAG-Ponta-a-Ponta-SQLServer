# Palestra RAG de Ponta a Ponta no SQL Server 2025

Bem-vindo ao repositório oficial da palestra **RAG de Ponta a Ponta no SQL Server 2025**.

Nesta palestra você aprenderá, na prática, como utilizar os novos recursos de Inteligência Artificial do **SQL Server 2025** para construir aplicações inteligentes utilizando **Embeddings**, **Busca Vetorial** e **Retrieval-Augmented Generation (RAG)** com modelos locais.

Aqui você encontrará todos os scripts utilizados nos Hands Ons da palestra.

O conteúdo está organizado na mesma sequência utilizada dos Hands On.
